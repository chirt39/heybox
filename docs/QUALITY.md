# 质量与验收计划

本文件是未来开发和发布的验收标准。初始基线仅做文件一致性与仓库隐私检查；现有解析、编辑、评分和怪物数值仍需专项验证。

## 必要样本

- 至少一份经用户授权且不入仓库的普通存档和一份深夜遗物较多的存档；记录文件大小、游戏版本及截图对照编号，不记录 Steam ID。
- 遗物：普通、深夜、独特、角色专属、夜王遗物、长词条及主词条后跟负面词条。
- 日志：概要、角色、夜王、累计、最高、深层区域字段；包含零值、上限值与已知异常值。
- 怪物：同名不同变体、四属性最高与最低倍率、缺失位置和缺失图片。
- 推荐：可装槽、不匹配颜色、不可叠加重复、必选缺失、互斥与无解。

## 验收表

| 领域 | 通过条件 |
| --- | --- |
| 存档解析 | 同一样本重复解析结果一致；关键计数与游戏画面逐字段对齐；无效文件有明确错误 |
| 存档编辑 | 导出前可取得原文件备份；只修改用户指定字段；重新解析能读回；游戏内复核步骤与风险已说明 |
| 遗物词条 | 每件遗物的数量、顺序、负面配对与截图一致；未知 ID 显示原值，不被丢弃 |
| 怪物资料 | 来源、变体、倍率、抗性和颜色提示一致；缺失与 0 可区分 |
| 推荐 | 槽位合法；同一规则与收藏结果可重现；每一项分数可追溯到词条和规则 |
| RAG 检索 | `backend/knowledge_base/evaluation_cases.jsonl` 中的预期记录可在配置的 top-k 范围内检出；记录 hit rate 与 MRR。检索命中不等同于答案事实已核验 |
| PC 界面 | 1280px 与常见宽屏下标题、词条、分页和弹窗不裁切；键盘可完成核心操作 |
| 隐私与发布 | 网络请求不传原始存档；公开仓库不含用户数据；线上版本与记录的 Git SHA 一致 |

出现未通过项时登记重现步骤、样本代号、期望值、实际值和责任对话。没有证据的项目标为“待核对”，不得写成“已校对”。
