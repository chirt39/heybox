# 多对话协作与路由

用户只需先找 **“渡夜图鉴｜项目总控”**。总控回答一般问题，或给出应进入的专项对话、可直接发送的任务说明、依赖资料和验收人。各对话不会自动共享聊天记录；本仓库文档、Issue 和 PR 是共同状态。

| 对话名称 | 负责范围 | 优先交付 | 避免直接修改 |
| --- | --- | --- | --- |
| 渡夜图鉴｜项目总控 | 需求、路由、优先级、跨模块接口、最终验收 | 需求决策、任务分配、集成结论 | 未经专项核对的数据数值 |
| 渡夜图鉴｜存档与逆向 | `.sl2` 格式、遗物和战绩字段、读写证据、隐私 | 字段字典、样本核对、解析与编辑接口 | 怪物资料和整站视觉 |
| 渡夜图鉴｜怪物数据 | 怪物 ID、变体、倍率、抗性、位置、图片及出处 | 数据审计台账、可追溯修正 | 存档解析和评分算法 |
| 渡夜图鉴｜遗物与配装 | 遗物目录、词条分类、流派规则和推荐解释 | 规则模型、评分核对、推荐接口 | 存档二进制写回和怪物数据 |
| 渡夜图鉴｜前端与美术 | PC 信息结构、组件、页面交互、视觉与可访问性 | 设计规范、页面实现和截图验收 | 原始游戏数值和存档字段结论 |
| 渡夜图鉴｜工程与发布 | 仓库、分支、集成、质量门槛、Sites 发布和回退 | CI／检查方案、版本记录、部署流程 | 产品规则的单方变更 |

## 一句话路由

- “这个功能该不该做、先做哪个、涉及两个模块”：项目总控。
- “存档读错、日志为零、字段偏移、导出不能读”：存档与逆向。
- “怪物倍率、弱点、分类、位置或图片错”：怪物数据。
- “词条筛选、不可叠加、流派规则或推荐不合理”：遗物与配装。
- “页面太大、留白、裁切、按钮或美术”：前端与美术。
- “GitHub、分支、上线、回退、构建故障”：工程与发布。

## 交接格式

专项对话向总控提交：需求 ID、问题或结论、证据链接／样本代号、修改文件、兼容影响、验收方法、未解决问题、PR 链接。总控确认依赖和用户反馈后更新任务状态。涉及两个模块时先写接口和负责人，再动手。

每个对话均按根目录 `AGENTS.md` 工作。新需求先由总控写入 `REQUIREMENTS.md` 并标明优先级；专项对话不把其他对话的聊天内容当作已定稿决策。
